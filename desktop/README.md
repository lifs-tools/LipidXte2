# desktop — Electron-Vue UI (optional)

> This directory was previously `web_app/frontend/`. **It is optional for production users** — the prebuilt static bundle in [`server/web/`](../server/web) is what the Node server serves at runtime. Rebuild from `desktop/` only when modifying the UI.

## What's here

An [electron-vue](https://github.com/SimulatedGREG/electron-vue) project (Vue 2) that produces two artifacts:

- An **Electron desktop app** (`npm run build`) for native macOS/Windows/Linux distribution.
- A **static web bundle** (`npm run build:web`) which is `rsync`'d into [`../server/web/`](../server/web) — the Node server serves that directory.

## Install

Cold install pulls in Electron and webpack 5 — expect ~5 minutes and several hundred MB.

```bash
cd desktop
npm install
```

## Build

```bash
npm run dev            # hot-reload electron at localhost:9080
npm run build          # electron app via electron-builder
npm run build:web      # static web build, rsynced into ../server/web/
npm run lint:fix
```

`build:web` does a destructive sync (`rsync -arvP --del`); anything in `server/web/` not regenerated by webpack will be removed.

## Source

Vue components live under [`src/renderer/`](./src/renderer); the Electron main process under [`src/main/`](./src/main).
